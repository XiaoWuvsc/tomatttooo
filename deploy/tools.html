TOOLS · 工具箱

选择一个工具

🖼️ 水印工坊

七款参数卡模板：参数叠层、原创底栏、两列底栏、深色底栏、铁路记录、玻璃浮层、虚化参数卡。EXIF 自动识别，批量 ZIP 导出。

进入 → 📷 EXIF 查看器

拖入一张相机直出的照片，立刻看到相机、镜头、焦距、光圈、快门、ISO、拍摄时间，一键复制参数。

进入 → ✂️ 画幅裁切

9 种比例裁切（1:1、4:3、16:9、9:16…），拖动取景框 + 三分线构图，导出尺寸可调。

进入 → 🧩 切图工具

九宫格 3×3 切图发朋友圈、三格横切拼图（竖图不切），一键导出 ZIP。

进入 → 🗜️ 图片压缩器

批量压缩照片：按质量、按目标大小、按尺寸，画质无差体积立减。

进入 → 🔄 格式转换器

JPG / PNG / WebP 互转，批量处理，质量可调，一键导出 ZIP。

进入 → 🎨 色彩提取器

提取照片主色调色板（前 8 色 + 占比），点色块复制色值。

进入 → 🧱 拼图工具

多张照片拼成一张：横排、竖排、四宫格、六宫格、九宫格，间距背景可调。

进入 → 📊 直方图查看器

亮度与 RGB 三通道直方图，曝光统计，一眼判断过曝欠曝。

进入 → 🔁 旋转翻转工具

批量旋转 90/180 度、水平垂直镜像翻转，原分辨率导出 ZIP。

进入 → ↔ 对比查看器

两张照片滑块对比：拖动分割线看调色前后、修图前后差异。

进入 → ⬜ 相框工具

加白边/色边相框，按 1:1、4:3、16:9 等比例出图。
